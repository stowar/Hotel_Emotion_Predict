# Hotel Emotion Predict

酒店评论情感分析系统 — 基于 PyTorch + FastAPI 的中文酒店评论情感分析服务，支持单条文本预测、批量文件处理、注意力权重可视化。

- **Backend**: FastAPI + PyTorch (双向GRU + Attention) + jieba 分词
- **Frontend**: 静态 HTML + ECharts 可视化
- **Python**: 3.10
- **Repo**: https://github.com/stowar/Hotel_Emotion_Predict
